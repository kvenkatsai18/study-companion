# Study Companion — AI Learning Partner

A voice-first AI study companion that talks to you, searches the web, helps with research, and creates study materials.

## What it does

- 🎤 Voice input — speak naturally, the AI listens
- 🗣️ Voice output — responds audibly with realistic speech
- 🤖 Animated avatar — a friendly robot face that animates while speaking
- 🔍 Web search — pulls real data from online sources
- 📚 Study assistance — helps with exam prep, research, learning any topic

## Tech Stack

- **Backend:** Python Flask
- **Voice:** Edge TTS (Microsoft)
- **AI:** MiniMax API
- **Frontend:** HTML/CSS/JavaScript
- **Avatar:** CSS-animated robot character

## Setup

1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Add your MiniMax API key to `.env`
4. Run: `python app.py`
5. Open `http://localhost:5000` in your browser
